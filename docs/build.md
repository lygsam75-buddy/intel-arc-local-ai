# 我们跑测的这台机器

**一句话**：它是**一台 2025 年的主流游戏机**，在**不换平台、不扩充**的前提下，
只换了一样东西 —— **一块显存更大的显卡** —— 因为只有这一样能改变「本地跑大模型能不能用」。

所以下面这些数字不是「服务器跑出来的」，是**一台普通桌面游戏机**跑出来的。
你要照着配，不需要买工作站。

---

## 1. 当前配置（全部实测取证，非抄规格书）

| 部件 | 型号 / 规格 | 取证方式 |
|---|---|---|
| **CPU** | AMD **Ryzen 5 9600X** · 6 核 / 12 线程 · 基频 5.0 GHz · **带核显** · 支持 AVX-512 | `Win32_Processor` |
| **主板** | 技嘉 **B850M FORCE WIFI6E**（mATX · AM5） | `Win32_BaseBoard` |
| BIOS | **F8**（2026-05-21） | `Win32_BIOS` |
| **内存** | **2 × 16 GB DDR5-6400** 双通道（型号 `PGD5U64A32XX7-KSWC`） | `Win32_PhysicalMemory` |
| 内存槽 | **4 槽，已用 2 槽**；主板最大支持 128 GB | `Win32_PhysicalMemoryArray` |
| **显卡** | **Intel Arc Pro B70 32 GB**（蓝戟 GUNNIR · `DEV_E223` / `SUBSYS_27421EF7`） | `gpu_identity.py` |
| 显卡可用显存 | **31.16 GiB**（ECC 关闭态） | `torch.xpu…total_memory` |
| **核显** | AMD `Radeon(TM) Graphics`（UMA）· 固定 512 MB + 动态共享 | `Win32_VideoController` |
| 显示输出 | **由核显负责**：2560×1440 @ 144 Hz；独显分辨率字段为空 | `CurrentHorizontalResolution` |
| **硬盘** | WD_BLACK **SN750 SE 1 TB** + WD **500 GB**，均为 NVMe SSD | `Get-PhysicalDisk` |
| **系统** | **Windows 11 专业版** · Build 26300 | `Win32_OperatingSystem` |
| 页面文件 | **64 GB 初始 / 128 GB 上限**（固定大小，非自动管理） | `Win32_PageFileUsage` |
| 电源 / 机箱 | **未登记**（见 §6） | — |

**两条 PCIe 槽**：1 条 **PCIe 5.0 x16**（CPU 直连）+ 1 条 **PCIe 4.0 x4**（芯片组）。
B70 插的是**CPU 直连槽**。

## 2. 它是怎么改过来的：只换了一块卡

| | 之前 | 现在 |
|---|---|---|
| 显卡 | 2025 年的游戏显卡（**已拆**，型号未登记） | **Arc Pro B70 32 GB** |
| CPU / 主板 / 内存 / 硬盘 | — | **一件没动** |

> 这也是为什么本手册里「16 GB 显存档要卸专家」「32 GB 内存 + 大页面文件」这些结论值得看 ——
> 它们全部来自**一台没被拆改过的普通桌面机**，不是特调的测试平台。

---

## 3. 为什么是「换显卡」，不是加内存 / 换平台

四条路都算过：

| 想法 | 为什么没走 |
|---|---|
| **加内存** | 槽是够的（4 槽只用 2），但 2026 年内存处在涨价周期 —— 同样的钱花在显存上收益大得多 |
| **加了也没用** | 跑不动 H3 是**显存**不够，不是内存不够。内存翻倍不会让 19 GB 权重塞进更小的显存 |
| **换平台 / 换 CPU** | 动的是整机成本；而且 CPU 不是主要瓶颈（MoE 解码吃带宽，预填充才吃算力） |
| **插两张卡** | 主板只有 1 条 CPU 直连 x16 + 1 条芯片组 x4，插不满两条全速；且双卡是买**容量**不是买速度 |

→ 结论：**能改变「能不能用」的只有一个变量 —— 显存容量。**
所以动作就是「换一块 32 GB 的卡」，其余不动。

**为什么 32 GB 是那道线**：16 GB 档跑 H3 必须把专家卸到 CPU（速度掉一截，Vulkan 的优势也从
1.65× 塌到 1.12×）；32 GB 档才能整块驻留。这条有实测，见 [`comfyui-h3.md`](comfyui-h3.md)。

## 4. 显示接法：显示器插主板，不插显卡

```
显示器 ──HDMI/DP──> 主板（核显 AMD Radeon）   ← 桌面、浏览器、视频解码全在这
                          │
Arc Pro B70（独显）────────┘ 不驱动任何显示，显存与 GPU 时间全给模型
```

实测这套接法下：独显上只有 ComfyUI 一个进程、占 **70 MB**；显存满额 **31.16 GiB**。
完整依据与「接错了怎么查」见 [`test-rig.md`](test-rig.md) 的「核显 + 独显共存」一节，
以及 [`install.md`](install.md) §6.1。

## 5. 这台机器的边界（也是本文结论的边界）

| 项 | 实测到哪 |
|---|---|
| 内存 | **32 GB**（可见 31.11 GiB，其中约 0.9 GB 被核显占走） |
| H3 视频 | 五档分辨率全通，最高做到 **1920×1088 / 841.55 s** |
| **2560×1440 及以上** | **没测**（显存与时间成本过高） |
| 长时满载（> 1 h） | **没测**（只做了单任务峰值） |
| 只有一张卡 | 双卡并发**没测**，T-11 仍是 ⛔ |

---

## 6. 没有登记的两项

| 项 | 为什么 |
|---|---|
| **电源型号 / 额定功率** | Windows 读不到 PSU 铭牌（`Win32_*` 里没有这个字段），只能看实物。本表**不写猜测值** |
| **机箱** | 同上，对跑分无影响，不登记 |

> 如果你要照这个配置装机，显存 32 GB 的卡在满载时整卡功耗实测 **P90 恒定 290 W**，
> 电源怎么选按你整机算 —— 本手册不替你拍电源功率。
